# Development instructions

This is a game-agent laboratory, not a solved Zelda bot. Read README.md and docs/STATUS.md before changing scope.

- Python 3.12+, uv, FastAPI/SQLAlchemy; React/Vite/TypeScript; native C++20.
- Run `uv run pytest -q` and `cd web && npm run build`. The C++ lease test requires g++ or clang++ and skips when absent. Never describe a skipped build as successful.
- Preserve the explicit simulator label. Never silently fall back from Codex/OpenRouter/SoH to demo responses, synthetic metrics or fabricated gameplay.
- Unknown usage/cost is null. Cached/reasoning tokens are subsets. Record failures and paid output truncation; never retry paid requests without the operator choosing to do so.
- Keep state and prompts bounded; video capture is local to the browser. No screenshots to models by default.
- Keep Codex auth inside the official CLI profile. Do not read/exfiltrate OAuth tokens, commit credentials, or convert subscription tokens to API keys. Test real providers only with explicit operator authorization and a configured budget.
- The cognition model selects the next typed strategic objective plus `ObjectiveCompletion`; it never selects skills or raw buttons and does not get developer shell access. For a trackable objective, runtime must keep objective/completion immutable until structured telemetry proves completion. Scene transitions, stuck signals, waypoint completion, route failure and unrelated durable progress are local motor evidence and must not replace the objective. Semantic dialogue choice may be a transient model call but must preserve the locked objective. Manual/untrackable objectives are the only fallback that may retain legacy event-driven reconsideration. Raw N64 control belongs to the local ML policy.
- V3 motor semantics: PPO samples a latent residual stick; the executed N64 stick is a deterministic mix of that residual and structured guidance. PPO log-probs belong to the latent residual action, not the mixed executed stick. Preserve both `policy_stick` and executed `stick` correctly in rollouts; do not move guidance back into an unbounded Beta prior that the network can numerically overpower.
- Do not make structured targets permanent collision-blind magnets. Movement intents may bend guidance only from currently observed local collision probes; do not add hidden routes or semantic navigation macros. Explicit traversal affordances and interaction targets must not be steered away merely because they terminate at collision. Prolonged local dwell may weaken only a direct/stale cognition target; it must not weaken a learned route, observed frontier, or native scene exit, because those have their own expiry/exhaustion logic. Straight-line intent reward must be suppressed while the executed guidance is collision-blocked or following a learned detour.
- Route memory may reuse only positions and directed edges Link actually traversed. Persist the actual observed crossing/gateway position for each directed edge and replay that gateway instead of trusting a coarse node centroid. Never synthesize reverse edges, shortcuts through collision, or walkthrough knowledge. A learned edge must be health-checked during replay: bounded lack of geometric progress must put it in temporary cooldown, increase failure cost and force replanning rather than letting it remain a permanent attractor. Partial route endpoints still use their separate exhaustion rule. Targetless exploration may choose a local frontier only from current collision probes, must hold one world-space frontier for a bounded attempt, cool down failures, and suppress rearward candidates while a forward/side probe exists. Keep training route memory persistent, isolate incompatible contexts, evaluation read-only, and freeze route memory with champions.
- Never hard-code semantic button mappings such as `Open -> A` or `Next -> A`. Contextual interaction discovery may override PPO with one physical button at a time, must mark those transitions non-trainable for PPO log-prob correctness, may persist only an empirically successful context-action/button mapping, and must evict a learned mapping after repeated replay failure. While `dialogue.active` or the pause menu owns the game, movement guidance/frontier selection must not continue underneath the modal state; linear dialogue advancement may be learned causally from observed text change/closure.
- Native input must expire, release on stop, reject stale/cross-scene packets, and remain limited to controller input. No teleports, HP writes, or hidden solution flags in observations.
- Preserve SoH as a separate checkout pinned by the integration script. Do not hard-reset user source/assets or distribute ROMs, saves or copyrighted game data.
- Capture actual validation in docs/STATUS.md. No claim of autonomous completion, learned aiming or reliable navigation before reproducing it in the game.
- Completion champions are immutable evidence artifacts. Training `game_completed` must snapshot only after final PPO work settles. Evaluation must never train, save over, quarantine/move, or otherwise mutate a champion; invalid champions fail closed. Keep evaluation deterministic at the motor-policy level.
- Coarse-area dwell pressure is intentional anti-loop shaping: fine movement, button churn and revisits must not reset it. Reset only for genuinely new macro-region expansion or meaningful game progress; do not weaken it back into a "player moved this frame" check.
- Frontier shaping is the directional complement to dwell punishment. Reward only new maximum outward radius and first-time coarse macro-region expansion; circling/revisiting an already reached radius must not pay. Keep this game-generic rather than encoding a Zelda route.
- Resource pickup rewards must be delta-based: no rupee/ammo/health/magic increase means no pickup reward. Do not reward `item_received` alone because full-capacity pickups may emit interaction telemetry without improving state. Chest-open reward is separate and one-shot via native treasure flags.
- UI direction: minimal realtime instrument panel. Show connection, operational thought, raw stick/buttons, token usage/API cost when known, and provider quota. Do not reintroduce skill/debug/navigation tabs into the primary UI.
- No GitHub Actions required. Prefer local checks; generate dependency lockfiles after an actual successful resolve and do not invent them.
